	## Before you start

	Sessions run inside a workspace, so open (or create) the workspace you want to work in first.

	## Open a session

	<ol class="chorus-steps">
		<li>
			<h4>Open your workspace</h4>
			<p>From Workspaces, open the one you want to work in.</p>
		</li>
		<li>
			<h4>Start a new session</h4>
			<p>Select <strong>Start session</strong>. <span class="chorus-draft">confirm label</span></p>
		</li>
		<li>
			<h4>Choose your resources</h4>
			<p>If prompted, pick the computing resources you need - for example more memory for large datasets. <span class="chorus-draft">confirm options</span></p>
		</li>
		<li>
			<h4>Wait for it to launch</h4>
			<p>Your secure environment opens in the browser, ready to use.</p>
		</li>
	</ol>

	## While it runs

	Inside a running session you launch apps and work with the data in your workspace, moving between tools without leaving the secure environment.

	## What's next

	To choose the right resources and understand when a session stops, see <a href="/docs/sessions/resources-and-lifecycle">Resources &amp; lifecycle</a>.
