	## Who can create one

	Anyone can create a **personal** workspace for their own work. **Collaborative** workspaces - those tied to a project - are set up by the project's principal investigator.
	<span class="chorus-draft">confirm creation permissions</span>

	## Create a workspace

	<ol class="chorus-steps">
		<li>
			<h4>Go to Workspaces</h4>
			<p>From the dashboard, open <strong>Workspaces</strong>.</p>
		</li>
		<li>
			<h4>Start a new workspace</h4>
			<p>Select <strong>Create workspace</strong>. <span class="chorus-draft">confirm label</span></p>
		</li>
		<li>
			<h4>Name and describe it</h4>
			<p>Give it a clear name and a short description so collaborators know its purpose.</p>
		</li>
		<li>
			<h4>Choose personal or collaborative</h4>
			<p>Decide whether it is private to you or shared with a team.</p>
		</li>
		<li>
			<h4>Save</h4>
			<p>Your new workspace opens, ready for data and tools.</p>
		</li>
	</ol>

	## What is next

	For a collaborative workspace, the next step is adding people - see <a href="/docs/workspaces/manage-members-and-roles">Manage members &amp; roles</a>.
