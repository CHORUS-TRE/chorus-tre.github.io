	## The core idea

	Sensitive data should not be moved into uncontrolled environments. CHORUS turns that around: computation, tools, and users come into a secure environment where the data stays protected. Research can proceed without compromising privacy, institutional control, or regulatory obligations.

	## What it brings together

	CHORUS combines secure data access, analytical tools, scalable compute, and governance workflows into one integrated system. Every step - from data ingestion through analysis to result export - happens under controlled, traceable conditions.

	## Communities on CHORUS

	CHORUS supports multiple scientific communities on a shared platform. **CHORUS.HIP** is dedicated to intracerebral EEG and neuroimaging; **CHORUS.EBRAINS** supports broader neuroscience. Each provides domain-specific data, tools, and governance while sharing the same architecture, and a single user can belong to several.

	## Who it is for

	CHORUS is for institutions that need to deploy secure Trusted Research Environments, and for researchers who need to collaborate on sensitive data without moving it out of institutional control.
