	## What apps are

	An app is a software tool used to work with data inside CHORUS - for example Jupyter, RStudio, or VS Code, alongside domain-specific applications. Apps run inside a session, on the platform's infrastructure.

	## Pre-approved and contained

	Every app is pre-approved and runs within the secure environment. Because nothing is installed on your own machine and the app works on data in place, sensitive data stays contained throughout.

	## Where apps come from

	Available apps live in the **App Store**, the catalogue you add tools from. See <a href="/docs/apps/the-app-store">The App Store</a>.
