	## What a session is

	A session is a live, secure environment that gives you access to applications and computing resources. Your tools run inside it, on the platform&apos;s infrastructure - never on your own computer.

	## Start a session

	<ol className="hip-steps">
		<li>
			<h4>Open your workspace</h4>
			<p>From Workspaces, open the one you want to work in.</p>
		</li>
		<li>
			<h4>Start a new session</h4>
			<p>Select <strong>Start session</strong>. <span className="hip-draft">confirm button label</span></p>
		</li>
		<li>
			<h4>Choose your resources</h4>
			<p>If prompted, pick the computing resources you need - for example, more memory for large datasets. <span className="hip-draft">confirm resource options</span></p>
		</li>
		<li>
			<h4>Wait for it to launch</h4>
			<p>Your secure environment opens in the browser, ready to use.</p>
		</li>
	</ol>

	## While your session runs

	Inside a running session you launch apps and work with the data in your workspace. The session holds everything that&apos;s running, so you can move between tools without leaving the secure environment.

	## Stopping a session

	When you&apos;re finished, stop the session to free up resources. Your data and results stay saved in the workspace. <span className="hip-draft">confirm what persists between sessions</span>

	## What&apos;s next

	With a session open, you&apos;re ready to launch a neuroscience tool and start analyzing.
